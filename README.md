# MAMONOV Запись экрана / MAMONOV Screen Recorder

Простая программа для записи экрана.

## Возможности
- Одна кнопка: Начать запись / Остановить запись (продолжение в тот же файл)
- Вторая кнопка: Сохранить
- Панелька не попадает в видео
- Звук с микрофона (если есть)
- Весь экран
- Минимум ресурсов (ffmpeg + аппаратное ускорение)
- Папка на рабочем столе с фирменной иконкой
- Русский/английский интерфейс по языку Windows

## Требования
- Windows 10+ (2004+ для скрытия панели из захвата)
- Python 3.10+
- ffmpeg (в PATH)
- Pillow (для фирменной иконки папки)

## Запуск
```
python recorder.py
```
