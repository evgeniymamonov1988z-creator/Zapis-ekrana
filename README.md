# MAMONOV Запись экрана / MAMONOV Screen Recorder

Простая программа для записи экрана.

## Возможности
- Кнопка «Запись»: старт / пауза / продолжить
- Кнопка «Сохранить»: стоп + склейка + файл готов
- Кнопка «Обновить»: обновление из Git-репозитория
- Кнопка «Лог»: просмотр лога, клик = копировать
- Панелька не попадает в видео (Windows 10 2004+)
- Звук с микрофона (если есть, с поддержкой кириллицы через bat-файл)
- Весь экран
- Минимум ресурсов (ffmpeg + аппаратное ускорение)
- Папка на рабочем столе: Mamonov/Mamonov video/

## Требования
- Windows 10+ (2004+ для скрытия панели из захвата)
- Python 3.10+
- ffmpeg (в bin/ рядом с программой или в PATH)
- Git (для автообновления)

## Запуск
```
python screen_recorder.py
```

## Файлы
- `screen_recorder.py` — основная программа
- `updater.py` — модуль автообновления через Git
- `install.py` — установщик (ffmpeg + Pillow + ярлык)
